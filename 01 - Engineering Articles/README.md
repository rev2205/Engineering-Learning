# Engineering Articles and Publications

Read one useful article a week. For each, record the problem, constraints, architecture, decision, rejected alternative, failure mode, evidence and transferable lesson.

## First-party sources
- [Cloudflare Blog](https://blog.cloudflare.com/) — networking, edge systems, security and incidents.
- [Netflix TechBlog](https://netflixtechblog.com/) — distributed systems, data and reliability.
- [Google SRE](https://sre.google/) — reliability and incident response.
- [Amazon Builders' Library](https://aws.amazon.com/builders-library/) — timeouts, retries and safe operations.
- [Stripe Engineering](https://stripe.com/blog/engineering) — APIs and infrastructure.
- [Uber Engineering](https://www.uber.com/blog/engineering/) — data and platform systems.
- [GitHub Engineering](https://github.blog/engineering/) — developer platforms.
- [Discord Blog](https://discord.com/blog) — scaling and real-time systems.
- [CNCF Blog](https://www.cncf.io/blog/) — cloud-native ecosystem.
- [Google Cloud Architecture Center](https://cloud.google.com/architecture) — architectures and trade-offs.

## Suggested reading order
Networking; Linux; containers; Kubernetes; observability; deployment safety; distributed systems. Prefer primary engineering accounts and official documentation. Treat benchmark claims in context.
