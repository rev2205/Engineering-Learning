# Failure Drill Worksheet

**Lab / date / authorized environment:**  
**Reset plan:**  

## Baseline
Expected healthy behavior and baseline observations.

## Fault introduced
Change exactly one thing and keep it reversible.

## Prediction
What symptoms do I expect? What else could cause similar symptoms?

## Investigation
First signal; evidence collected; hypotheses ruled out; root cause in the lab.

## Recovery
Fix; verification that service is healthy; residual risk.

## Learning
What was the earliest useful signal? What would improve a runbook or alert? How would this differ in production?
